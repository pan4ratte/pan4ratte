## Obsidian plugins

- **Citation Suite** — Cite literature in Pandoc style from your Zotero library, view formatted reference list in the sidebar, preview citations with citation styles, automate footnotes creation, and more. [GitHub](https://github.com/pan4ratte/obsidian-citation-suite) · [Obsidian Store](https://community.obsidian.md/plugins/citation-suite)
- **Pandoc GUI** — Export and import notes via Pandoc with a modern GUI both on desktop and mobile. Create templates for Word, PDF, LaTeX, HTML, EPUB, and many other formats, and install dozens of lua filters from the store. [GitHub](https://github.com/pan4ratte/obsidian-pandoc-gui) · [Obsidian Store](https://community.obsidian.md/plugins/pandoc-gui)
- **Classy PDF Extractor** — Import all types of annotations from PDFs inside and outside your vault, with highly flexible settings and templates. [GitHub](https://github.com/pan4ratte/obsidian-classy-pdf-extractor) · [Obsidian Store](https://community.obsidian.md/plugins/classy-pdf-extractor)
- **Advanced Word Count** — Create complex word count presets that will be displayed in the status bar or in the right pane tab. Install tens of community presets, custom metrics, and settings from the extension store. [GitHub](https://github.com/pan4ratte/obsidian-advanced-word-count) · [Obsidian Store](https://community.obsidian.md/plugins/advanced-word-count)
- **Regex Quick Actions** — Create and quickly apply regex commands via command palette, context menus and hotkeys. Made for automation purposes. [GitHub](https://github.com/pan4ratte/obsidian-regex-quick-actions) · [Obsidian Store](https://community.obsidian.md/plugins/regex-quick-actions)
- **Tags Color Files** — Automatically color files in the file explorer and Bases, and links to them in notes, based on the tags they contain and the rules you create. [GitHub](https://github.com/pan4ratte/obsidian-tags-color-files) · [Obsidian Store](https://community.obsidian.md/plugins/tags-color-files)
- **Publish to Telegram** — Post notes directly to Telegram channels, groups and personal messages with different presets and advanced publishing settings. [GitHub](https://github.com/pan4ratte/obsidian-publish-to-telegram) · [Obsidian Store](https://community.obsidian.md/plugins/publish-to-telegram)

## Other academic projects

- **Zotero GOST Styles** — Carefully crafted Zotero citation styles following the Russian GOST R 7.0.5-2008, R 7.0.100-2018 and R 7.0.108-2022 standards, with multilingual localization, Ibid. and short-form repeat citations. [GitHub](https://github.com/pan4ratte/zotero-gost-styles)
- **IT in Scientific Research** — Official repository of my course on using Obsidian, Zotero, Pandoc and Calibre in research, including Pandoc Lua filters and Word templates (in Russian). [GitHub](https://github.com/pan4ratte/course-it-in-science)
- **Calibre Modern GNOME** — A modern, clean icon theme for Calibre based on Ubuntu's Yaru-Blue style. [GitHub](https://github.com/pan4ratte/calibre-modern-gnome)

## Browser extensions

- **OpenTiles** — A free, modern, open-source and highly customizable visual bookmark manager and start page for your browser. [GitHub](https://github.com/pan4ratte/open-tiles) · [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/opentiles/)
